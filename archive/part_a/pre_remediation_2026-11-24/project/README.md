# JSE transformation-policy event studies — Part A

This R research project supports Monique van Eeden's Stellenbosch University Economics thesis, supervised by Dr Krige Siebrits, on the efficiency–equity tradeoff in transformation policy. It measures short-horizon stock-market reactions; it does not estimate realised profitability, productivity or equity gains. Parts B and C are outside scope.

The existing licensed IRESS source handover is **immutable**: `data/thesis_data/`, version 1.2.0. The verified policy register is `research/events.csv`. Analysis outputs are preliminary and require methodological review before thesis use.

## Setup

R 4.3.3 was used. Required R packages: `data.table`, `yaml`, `ggplot2`, `jsonlite`, `digest`; testing also requires `testthat` and `withr`. `renv.lock` records these and their recursive dependencies. No R Arrow installation is needed: a small local Python/PyArrow bridge handles Parquet I/O, schema/key checks and fingerprints only. All returns, sample screens, estimation, inference, plots and reports are calculated in R.

From `mon_thesis/`:

```sh
Rscript -e 'renv::restore(prompt = FALSE)'
# If renv itself is absent:
# Rscript -e 'install.packages("renv", repos="https://cloud.r-project.org")'
```

The execution environment already has Python/PyArrow 26.0.1 in `../iress-export/.venv/bin/python`; the configuration uses that relative path. A portable alternative is:

```sh
python3 -m venv .venv-io
.venv-io/bin/python -m pip install -r requirements-io.txt
export PART_A_PYTHON="$PWD/.venv-io/bin/python"
```

Keep the virtual-environment interpreter path intact; resolving its symlink to the system executable loses its package environment. No credentials or source-data acquisition are needed. Full observed source data stays local; do not publish licensed data or generated firm-level price histories without permission.

## Execute

```sh
Rscript run_analysis.R --event mining_charter_2017
Rscript run_analysis.R --event mining_charter_2018
Rscript run_analysis.R --all
Rscript run_analysis.R --smoke
Rscript tests/testthat.R
```

The entry point locates its own project directory, so `Rscript mon_thesis/run_analysis.R --all` also works from the parent repository. Each analysis first runs the supplied package verifier, validates data contracts and joins, constructs returns, selects securities, estimates models, calculates outcomes and bootstrap inference, re-estimates sensitivity/placebo studies and generates outputs. A failed event is recorded and makes the process exit nonzero after supported events finish. Optional inference failures remain explicitly labelled in the inference table.

`--smoke` uses only 2017, 199 rather than 4,999 bootstrap draws and reduced sensitivities/placebos. It overwrites the latest results and labels them SMOKE. Use `--all` to regenerate the full deliverable. `--no-robustness` explicitly disables re-estimation checks. `--config path.yml` selects an alternative configuration. All runs overwrite latest-run aggregate files; an event-only run contains that event only. Preserve a copy of `outputs/` if comparing runs. Figures from earlier event runs may remain; `run_metadata.json` lists the current run events.

The tests require `data/derived/returns_daily.parquet`, generated by any successful pipeline run. The real-data integration test reruns source verification and the 2017 analysis in a clean R session; it is not silently skipped when inputs are absent.

## Structure and outputs

- `config/analysis.yml`: paths, event selection, screens, windows, resampling and placebo seeds.
- `R/00_*.R` through `R/08_*.R`: validation, returns, samples, models, abnormal returns, inference, exposure, robustness and reporting; `R/utils.R` supplies checked I/O/joins.
- `scripts/parquet_bridge.py`: local format/contract operations, no financial calculations.
- `data/thesis_data/`: original package; never modify its README, manifest or payload.
- `data/derived/`: generated return panel, market returns, event samples, OLS estimates, AR, firm CAR and balanced daily portfolio datasets, all Parquet.
- `outputs/diagnostics/`: source checks/fingerprints, configuration, execution environment, return-quality/extreme audits, sample counts, model flags, event status, numerical test outcomes and simulation calibration.
- `outputs/tables/`: fractional-return CSVs; inference also has a readable Markdown version. CAR summaries distinguish complete samples by window. Security counts are not issuer counts.
- `outputs/figures/`: 300-dpi PNG and PDF CAAR plots with pointwise intervals, beta distributions and sensitivity comparisons.
- `outputs/reports/part_a_preliminary_results.md`: actual numerical results, methods, interpretation and remaining work.
- `docs/`: detailed methods, sampling, inference, limitations and executed progress/handover.

Every output set is tied to the source manifest SHA-256, event-register/code/config hashes, effective configuration, software versions and recorded deterministic seeds in `outputs/diagnostics/run_metadata.json`. Source fingerprints are compared before/after execution. Generated large data and local libraries are ignored by Git. Repeated runs with identical inputs/configuration produce identical statistical tables; timestamps and PDF metadata can differ.

## Research design and cautions

Baseline: simple raw closing-price returns with strict calendar adjacency; OLS market model fitted over sessions −250:−30; at least 180 positive-volume benchmark-paired returns; at most 20% unchanged valid returns; exclude known likely non-company securities from historical bulletin flags. Unknown industry remains unknown. Primary CAR is [0,+1]; other windows are sensitivity/anticipation checks.

Mining announcements compare equal-security-weight historical mining candidates and non-mining controls. Broad EE/B-BBEE events have aggregate market-model results without an identified treatment comparison. Date-synchronous residual moving blocks preserve cross-security common shocks and propagate firm-specific parameter estimation error. See `docs/statistical_inference.md` for formulas and assumptions. Holm adjustment covers the five headline tests. No independent-firm t-test supplies primary inference.

Raw Close and J203 adjustment/return conventions are unverified. Announcement release timestamps and bulletin pre-publication availability remain unresolved. Industry is a provisional policy-exposure proxy; issuers, historical listings and security classes are not fully verified. Extreme price movements may be genuine or corporate actions. Market-benchmark contamination, anticipation, contemporaneous news, event-induced volatility and listed-firm selection prevent strong causal claims. Insignificant abnormal returns do not prove no policy effect.

Review `docs/research_progress.md`, the results report and `outputs/diagnostics/test_summary.md` for actual execution status. Provider definitions/corporate actions, timing, historical identities and inference assumptions require review before sending thesis-final findings to Monique.

## Execution environment notes

The existing system `waldo` 0.5.2 and newer `glue` require loading `glue` before testthat comparisons; the test entry point does so. No package sources or system libraries were changed. A network attempt to install waldo was unavailable; preloading resolved the namespace cycle. `renv` lockfile creation succeeded using a writable temporary cache:

```sh
RENV_PATHS_ROOT=/tmp/part-a-renv RENV_PATHS_CACHE=/tmp/part-a-renv/cache Rscript -e 'options(repos=c(CRAN="https://cloud.r-project.org")); renv::snapshot(packages=c("data.table","yaml","ggplot2","jsonlite","digest","testthat","withr","glue","renv"), lockfile="renv.lock", prompt=FALSE)'
```

In a restricted workspace, set `RENV_PATHS_ROOT`/`RENV_PATHS_CACHE` to a writable local directory before restoring. The lockfile was generated from installed versions; a fresh network restore was not executed in this session. The current installed environment and actual execution versions are recorded, including Python/PyArrow/Pandas in `source_contract.json`.

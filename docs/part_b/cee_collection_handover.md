# CEE collection handover

The 2016–2025 CEE management, reporting coverage and EAP datasets are independently checked and suitable for the qualified descriptive uses in `cee_independent_review.md`. The review compared all extracted source cells using a second PDF text library and inspected selected rendered pages; it did not visually proofread every cell. Preserve all source limitations and source references. No historical sector bridge has been established or required.

Run `sh analysis/part_b/scripts/reproduce_cee.sh` with the packages in `analysis/part_b/scripts/requirements.txt` and Poppler installed. The independent source checks additionally require PyMuPDF; run `python3 analysis/part_b/tests/independent_early_source_check.py`, `python3 analysis/part_b/tests/independent_pdf_semantic_check.py`, `python3 analysis/part_b/tests/independent_remaining_source_check.py`, `python3 analysis/part_b/tests/independent_check_cee.py`, and `python3 analysis/part_b/tests/final_collection_check.py`. The first two cover 2016–2019 and 2023–2024, and the third covers 2020–2022 and 2025. The first script includes a separate decoder for the 2018 nonstandard glyphs. Source PDF files are unchanged.

Use count-based national 2016–2024 and detailed sector 2019–2024 with the filters and source caveats in the review. 2016 national is retrospective; 2016 sector observations are percentage sums. Keep 2025 separate because its reporting population changed. Retain the 2019 management and 2023 coverage discrepancies and 2024 published percentage discrepancies; do not normalise source data. See `cee_issue_register.md`, `cee_data_dictionary.md` and `cee_visual_verification_log.csv`.

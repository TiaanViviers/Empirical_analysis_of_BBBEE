# Extraction methodology

The independent follow-up uses `independent_verify_mupdf.py` to compare MuPDF structured-text positions and source strings with all 35 retrospective tables, with rendered pages inspected for layout. `independent_figures_check.py` compares a fresh rendered-page transcription of the supplementary charts, and `independent_structure_check.py` checks final structure and calculations. Run these separately after reproduction; MuPDF is an optional review tool and is not required by the original pipeline. Detailed coverage and limits are in `bbbee_independent_review.md`.

The pipeline uses only the two acquired publications. The retrospective local PDF is processed with Poppler `pdftotext -layout`; source-scoped Python parsers capture the listed tables and explicitly assert year and row widths. Tables 16, 23, 28, 35, 42, 50, 60, 67, 74, 81 and 88 supply ownership. Four fields remain separate, decimal commas become decimal points, and the Property 2013 fourth cell remains blank. Table 1 supplies enterprise size and pilot Table 2 supplies sector composition. Counts with a printed dash remain missing. Source rows for Grand Total are preserved.

Pilot logic supplies national Tables 4–5 and the manually transcribed chart tables for the 2022 report. Sector Tables 20–21, 26–27, 32–33, 39–40, 47–48, 57–58, 64–65, 71–72, 78–79 and 85–86 supply status counts and percentages; Property percentage Table 58 is present although omitted from the index. Years are taken from the headers; MAC begins in 2017. Calculations divide by the published status total only when numeric cells reconcile, and do not silently change a source count. Total sample and status denominators need not coincide: the report states that blank/zero status inputs were excluded.

The supplementary figures 7, 8 and 10 are preserved as a separate series. The embedded chart values were manually transcribed by the pilot and compared to the rendered data tables again; printed Generic zeros in 2017–2018 have missing analytical values because the narrative explicitly says those years were not analysed.

A separate coordinate-grouping check reads Poppler bounding-box word coordinates, groups cells by their physical row and year column, and compares them with the layout extraction for every retrospective table. This is a second extraction method applied to the same PDF and the same underlying Poppler library, not an independent human audit. Rendered images of every requested retrospective table were inspected for title, population, headers, year and column alignment, with issue cells checked explicitly. The three supplementary figures were visually checked cell by cell. The verification log states precisely what was checked. The subsequent independent review inspected rendered source layouts and used a separate MuPDF numerical comparison, as detailed above.

Reproduction requires Python 3 standard library and Poppler `pdftotext`. A dedicated environment can be created with `python3 -m venv .venv-bbbee`; no Python packages are required (`requirements-bbbee.txt`). Invoke `.venv-bbbee/bin/python` only if changing the shell entry point or placing the venv on PATH. No Parquet engine is installed; CSV is the portable final format. The scripts make no network requests and never modify the source PDFs. SHA-256 checks detect local changes; they are not authentication. Copyright and redistribution restrictions remain applicable.

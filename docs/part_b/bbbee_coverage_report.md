The retrospective provides 11 rows per measure for all included sectors except seven for MAC. Property 2013 female economic interest is blank; no year was invented. Four supplementary Generic values in 2017–2018 are printed as zero but not analysed. The sector reference reflects Table 2 categories, while the ownership and compliance tables cover the ten specified sector codes. It is not a list of industries or CEE sector mappings.

Published percentages are whole percentages for compliance, while calculated values retain four decimal places. The reporting-coverage samples are contextual; financial-sector 2016 has 9 entries in Table 2 while the published compliance Table 78 total is 10. Annual sample composition changes substantially; neither those counts nor any ownership average establish a balanced panel or ownership-specific sample size.
